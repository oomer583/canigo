# The CanIGo name

The code is MIT licensed: you may copy, change and publish it. The MIT license covers the code only. It does not give you the right to use the CanIGo name.

People rely on CanIGo to decide whether they can physically get into a building. A copy that looks like CanIGo but shows different data, or collects data somewhere else, can send someone to a door they cannot get through. So:

- If you publish a copy, give it a different name.
- Do not use the same name or one that can be confused with it, including swapped or look-alike letters (for example İ, ı or l for I), the same logo, or the same look presented as the original.
- Do not suggest that your copy is the official CanIGo or is run by its author.
- Keep the note the app shows on unofficial addresses ("This is a copy, not the official CanIGo").

Official addresses are listed in [`src/official.js`](src/official.js). The main one is https://canigo-app.pages.dev.

If you find a copy that pretends to be CanIGo, please open an issue on GitHub.
